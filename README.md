# KEAAS

Knowledge & Expertise as a Service.

Premium corporate website for KEAAS — an Experts-as-a-Service partner for System Integrators.

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Framer Motion
- Lucide Icons

## Develop

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm start
```
